# Instructor guide

Teach from the same [course guide](../README.md) as learners. Before a runtime session, supply the qualified environment card, budget, deadline and allowed mutation scope from the [evidence contract](../references/pedagogy/evidence-contract.md). Don't present an unqualified GPU profile as ready to run.

1. Review [solutions and facilitation](pedagogical-v2/solutions.md), including analytical alternatives for missing access.
2. Prepare one isolated scenario from the [fault bank](pedagogical-v2/fault-bank.md) with a saved restoration procedure, and keep the solution hidden during the attempt.
3. Score evidence with the [rubric](pedagogical-v2/rubric.md), separating reasoning from execution.
4. For the capstone, change the customer requirements and pick an unfamiliar fault layer. Record hints, active time, waiting, resource costs and cleanup.

Independent reproduction and live GPU and product qualification are still outstanding; see [runtime readiness](../README.md#check-runtime-readiness).
