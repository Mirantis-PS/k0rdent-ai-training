# Optional extensions

Pick an extension by customer need, prerequisites, licensing and hardware access. None is a required stage of the core path, and each keeps its original content and validation state.

- [Bare metal](bare-metal/README.md): labs still under development; sandbox and BMC access required.
- [Virtualization](virtualization/README.md): the eight-GPU passthrough lab needs specialized hardware; further labs are unwritten.
- [Advanced Kubernetes](advanced-kubernetes/README.md): hosted control planes, networking and DRA, each with its own prerequisites and mixed historical validation.
- [Licensed orchestration](licensed-orchestration/README.md): Run:AI needs its documented licensed control plane; an alternative to the open KAI path.
- [ML platforms](ml-platforms/README.md): complete Jupyter, vector database, Kubeflow and MLflow labs with their storage and operator requirements.
- [Compliance](compliance/README.md): the FIPS exercise keeps its image and crypto gates; a stock-host smoke test isn't compliance certification.
- [Advanced inference](advanced-inference/README.md): TensorRT-LLM with its own driver, container and GPU compatibility path.
- [HPC](hpc/README.md): Slurm, with multi-node, host support and RWX storage prerequisites.
