# Week 2: Bare Metal as a Service

Week 2 moves from the k0rdent management plane into bare metal operations: exploring a pre-configured k0rdent sandbox, then registering and troubleshooting bare metal hosts over the Redfish BMC API using Metal3 tooling. The labs build on the environment and concepts from [Week 1](../week-1-foundations/README.md).

## Labs

| Lab | Title | Duration | Type |
|-----|-------|----------|------|
| 2.1 | [Explore k0rdent Sandbox](labs/lab-2.1-explore-sandbox.md) | 3 hours | Exploration / Familiarization |
| 2.2 | [BMC Discovery with Redfish](labs/lab-2.2-bmc-discovery.md) | 4 hours | Hands-on Technical |
| 2.3 | [Troubleshooting BMC Connectivity](labs/lab-2.3-troubleshooting-bmc.md) | 2.5 hours | Troubleshooting / Problem Solving |
